# Piece set: Alpha

**CC BY-SA 4.0**.

Source: https://github.com/lichess-org/lila/tree/master/public/piece
(the `alpha/` folder; fetched 2026-10). The 12 SVGs in `alpha/` are used as
fetched, unmodified. `board.css` and `PlayerBar.svelte` (captured-material
